# CellHack2: THE GOAL

**Build a cell that takes #1 on the ladder and stays there.** Nothing else counts as progress.

- Judge every idea, measure, test, review round and build against one question: does it make #1 more likely? If not, don't do it.
- No single mechanic (bite speed, cap rules, energy layout) is the goal. The user never asked to focus on any one mechanic.
- Before any build, state plainly how confident I am that it takes and holds #1, and why. If I'm not confident, say so and stop. Don't ship it, and don't polish it.
- Local pass bars only measure what the simulator can see (our own cells). Passing them does not mean the cell beats the #1 rival. Say so every time.
- Re-laddering a retired cell does NOT restore its old rating. Taking a cell off the ladder loses its rating.

Tracking: planning.md, issues.md, tasks.md at this folder's root.
